# Novel Writing Studio

This project keeps the manuscript in portable Markdown files under `novel/`.
The React app provides a live reading and planning view while Dyad's Agent
creates and revises the source files.

Use Plan mode to shape the premise and outline, Agent mode to write or revise a
scene, and Ask mode for critique that should not change files. The bundled
`novel-writing` project skill is discovered automatically when project skills
are enabled.
